# theunit-map

Map and navigation files for the THEUNIT app (Tunisia), published as GitHub release assets:

- `tunisia-YYYYMMDD.pmtiles` — vector map (Protomaps, built by `tools/map_build.py` in the THEUNIT repo)
- `tunisia-YYYYMMDD.valhalla.tar` — Valhalla 3.9.1 routing tiles (built by `.github/workflows/build.yml`)
- `tunisia-YYYYMMDD.search.sqlite` — offline search index (`tools/search_index.py`)

Data © OpenStreetMap contributors, ODbL. Map tiles © Protomaps.
